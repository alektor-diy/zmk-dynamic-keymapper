デモモードでサンプルのキーボードを編集中です。実機接続や解除キーは不要です。変更はデモ終了時にリセットされます。

このファームウェアでは保存ごとに解除キーを押します。接続時に一度だけ解除するには、ZDKM を含むファームウェアを更新してください。

    保存したマクロはキーマップやコンボの出力に割り当てられます。

      解除すると、切断するまで続けて設定を編集できます。

      マクロを削除

      マクロの手順を削除します。キーやコンボの割り当ては残り、同じ枠に新しいマクロを保存すると、その割り当てから実行されます。
