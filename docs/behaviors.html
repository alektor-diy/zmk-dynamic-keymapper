ZMK Dynamic Keymapper

割り当てる動作の一覧

ZMK と ZDKM の主な動作を解説します。メニューの項目は、接続したファームウェアで利用できる動作に応じて変わります。

キー入力とマクロ

Key Press &kp
選んだキーを押している間、そのキーを押下します。文字、修飾キー、メディアキーなどに使います。
Mod-Tap &mt
長押しのキーとタップのキーを別々に指定します。たとえば長押しを LCTRL、タップを A にできます。
Key Toggle &kt
指定キーの押下状態を切り替えます。もう一度押すと解放します。
Sticky Key &sk
指定キーを次の入力まで保持します。たとえば一度押した Shift を次の一文字に効かせます。
Grave/Escape &gresc
通常は Esc を出し、Shift または GUI キーを押しているときは Grave（US のバッククォート）を出します。
Caps Word &caps_word
英字を大文字にするモードです。区切りになるキーを押すと解除されます。
Key Repeat &key_repeat
直前に出力したキーをもう一度送ります。
Mouse Key Press &mkp
マウスのボタンを押します。左は 1、右は 2、中央は 4 です。
ZDKM Macro &zdkm_macro
マクロ画面で保存した枠を実行します。割り当て時に枠を選びます。

レイヤーと空きキー

Momentary Layer &mo
押している間だけ、指定レイヤーを有効にします。
Layer-Tap &lt
長押しで指定レイヤーを有効にし、タップでは指定キーを出力します。
Toggle Layer &tog
指定レイヤーの有効・無効を押すたびに切り替えます。
Sticky Layer &sl
次の入力まで指定レイヤーを有効にします。
To Layer &to
指定レイヤーに切り替えます。既定レイヤーを除くほかのレイヤーは無効になります。
Transparent &trans
下にある有効レイヤーの同じ位置の割り当てを使います。
None &none
その位置の入力を無効にします。下のレイヤーにも入力を渡しません。

接続と本体操作

Bluetooth &bt
Bluetooth プロファイルを操作します。ZMK v0.3 では 1, 0 が次へ、2, 0 が前へ、3, プロファイル番号 が指定先へ切り替える例です。ペアリングを消す操作もあります。
Output Selection &out
入力の出力先を選びます。0 で USB／BLE を切り替え、1 で USB、2 で BLE を選びます。
Reset &sys_reset
キーボードを再起動します。
Bootloader &bootloader
ファームウェアを書き込むためのブートローダーに入ります。
Studio Unlock &studio_unlock
ZMK Studio 側の設定ロックを解除します。
zdkm_unlock &zdkm_unlock
書き込みの案内が出ている間に押すと、Web GUI から同じ USB 接続中に書き込めます。旧ファームウェアや CLI では、書き込みごとに押します。
